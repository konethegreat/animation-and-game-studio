# Orbit Run

A one-screen arcade game built with Godot 4.7.2 and GDScript. Collect lime stars, dodge coral rocks, survive as long as you can.

Play: https://konethegreat.github.io/animation-and-game-studio/#play

## Controls

- Move: arrow keys, A / D, or drag with mouse or touch
- Start and retry: Space, Enter, click or tap

## Details

- 960x540, GL Compatibility renderer, single-threaded web export so it runs on GitHub Pages without cross-origin headers.
- Everything is drawn in code with `_draw()`. No sprite assets.
- Sound effects are generated by `audio/make_sfx.py` using the Python standard library.
- Best score persists in `user://orbit.cfg`.

## Reproduce

```bash
python audio/make_sfx.py
python ../../studio/studio.py export 003-micro-game
python -m http.server -d build/web 8000
```

Open http://localhost:8000 and play.
