# The Maker at Work

A 25 second pilot for a stylised portrait film, built from the maker's own photograph and made entirely on this machine.

The pilot is three shots: the night desk, the framed portrait, and the return with the title. The full film adds the four possibility worlds and the lantern from 004.

This is a stylised portrait, not a photoreal likeness claim. Close shots use the real photograph. The pilot uses only the photograph, with a depth mesh for parallax. Later wide shots may use a sculpted double, kept in silhouette or away from the camera. The face is never warped or replaced.

## Inputs

- `assets/private/portrait.png`: the public portfolio portrait, converted to PNG. Not committed.
- `assets/private/portrait_plate.png`: the graded 2.4:1 film plate, built by `portrait.py`. Not committed.
- `assets/private/portrait_graded.png`: the dimmer graded print that sits in the frame on the desk. Not committed.
- `assets/private/portrait_plate_depth.png`: a monocular depth map from Depth Anything V2, built by `portrait.py --depth`. Not committed.
- `assets/private/voice-reference.m4a`: the owner's voice reference. Not committed.
- `assets/repo/fonts/Fraunces.ttf`: title type, OFL.
- `audio/pilot.flac`: the original score, generated by `score.py`.
- `audio/pilot-mix.flac`: the score plus three cloned lines, built by `mix.py` from the takes in `assets/private/voice/`. This is the manifest's mix.

Only the encoded film, poster and project source are published. The raw portrait, depth map and voice reference stay private.

## Reproduce

```bash
./.venv/Scripts/python projects/010-maker-at-work/portrait.py --depth
./.venv/Scripts/python projects/010-maker-at-work/score.py
./.venv-ml/Scripts/python projects/010-maker-at-work/voice.py --test
./.venv-ml/Scripts/python projects/010-maker-at-work/voice_qa.py
./.venv-ml/Scripts/python projects/010-maker-at-work/voice.py
./.venv/Scripts/python projects/010-maker-at-work/mix.py
./.venv/Scripts/python studio/studio.py render 010-maker-at-work
./.venv/Scripts/python studio/studio.py verify 010-maker-at-work
```

`render` resumes per shot. Use `--shot s01-desk` for a single shot and `--preview` for a half resolution pass.
